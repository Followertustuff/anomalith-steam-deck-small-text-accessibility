- Menus or subtitles are difficult to read on the built-in handheld display.
- Text becomes blurry when applying non-native output scaling.
- Important icons or controls are hard to distinguish at a small screen size.

## 🛠️ Step-by-Step Troubleshooting

1. Inspect the game’s available subtitle, text-size, HUD and interface options without assuming a specific control exists.
2. Test the Steam Deck magnifier accessibility shortcut for occasional small text.
3. Compare the native handheld resolution with any in-game scaling choices.
4. For docked play, test on a larger display while preserving the same save and game version.
5. Record which screens remain unreadable and provide examples to the developer as accessibility feedback.
